## 🚀 Featured Projects

### 1. MedCare – Appointment Booking System

A full-stack healthcare appointment management platform with separate patient and doctor dashboards.

**Technologies:** React.js, Node.js, Express.js, MongoDB, JWT, REST APIs and Render.

**Key Features:**

- Patient registration and authentication
- Doctor authentication and dashboard
- Appointment booking and cancellation
- Appointment status management
- Patient ratings and reviews
- Role-based access control
- JWT authentication and bcrypt password hashing
- API rate limiting and Helmet security headers
- Restricted CORS configuration
- MongoDB-based duplicate booking prevention
- Cloud deployment using Render and MongoDB Atlas
